# 验收清单（Acceptance Checklist）

项目：supermdp — Wails 桌面只读 Markdown 预览器
用途：验收者（reviewer）按此清单逐项测试，输出验收报告 docs/acceptance/report.md。

## A. 构建与运行
- [ ] `go build ./...` 无错误
- [ ] `go vet ./...` 无警告
- [ ] `npm run build`（tsc + vite）无错误
- [ ] `wails build` 产出可执行文件，双击启动不崩溃、无控制台报错
- [ ] 窗口尺寸合理，最小 800x600 可正常布局

## B. GFM 渲染正确性（用 docs/acceptance/fixtures/sample.md 验证）
- [ ] 标题 h1-h6 层级正确、锚点生成、TOC 目录正确嵌套
- [ ] 粗体/斜体/删除线/行内代码
- [ ] 有序/无序/嵌套列表、任务列表（checkbox 可交互展示）
- [ ] 表格：对齐、单元格内行内格式、转义 `\|`
- [ ] 引用块（含嵌套）、水平线
- [ ] 链接：行内/引用式/自动链接（URL 与邮箱）；图片
- [ ] 脚注、围栏代码块（带语言）、HTML 转义
- [ ] 断行/软换行符合 CommonMark 预期

## C. 代码高亮
- [ ] ≥20 种语言抽查（js/ts/python/go/rust/java/c/cpp/bash/sql/json/yaml/html/css/dockerfile/xml/markdown/diff/powershell 等）关键词着色正确
- [ ] 无语言标注的代码块有合理的默认样式
- [ ] 语言标签显示 + 复制按钮可用（复制内容正确）

## D. KaTeX（可开关）
- [ ] 行内 `$...$` 与块级 `$$...$$` 渲染正确
- [ ] 复杂公式（分式/矩阵/求和）显示正常，长公式横向滚动不溢出
- [ ] 关闭开关后公式退化为纯文本
- [ ] 非法公式优雅降级（不白屏不报错）

## E. mermaid（可开关）
- [ ] flowchart / sequenceDiagram / gantt / pie 至少四类图渲染正确
- [ ] 关闭开关后图表源码以代码块显示
- [ ] 多图共存、图与正文间距正常

## F. 文件操作
- [ ] 工具栏"打开"按钮弹出原生文件对话框，过滤器只显示 md/markdown/txt
- [ ] 拖拽 .md 文件到窗口可打开
- [ ] 打开后外部修改文件 → 300ms 节流后自动刷新，状态栏更新时间
- [ ] 文件被删除/重命名 → 前端有明确提示
- [ ] 切换打开另一个文件正常；刷新按钮重新读取
- [ ] UTF-8 BOM 文件、GBK 编码文件均能正确显示（不乱码）
- [ ] 空文件、只有空白的文件显示为空状态而非报错

## G. 性能
- [ ] 5MB 大文件（混合段落/代码块/表格）打开到可交互 < 2s
- [ ] 大文件滚动流畅，无持续卡顿；渲染不阻塞 UI 交互（能正常切换主题等）
- [ ] 连续快速修改文件（节流）不产生渲染风暴

## H. 安全（XSS）
- [ ] `<script>`、`<iframe>`、`onerror` 事件、`javascript:` 链接、`<img src=x onerror=...>` 均被清洗，不执行
- [ ] DOMPurify 配置允许 katex/mermaid 所需 class/style，但禁止脚本执行
- [ ] 渲染后 DOM 无注入的可执行属性

## I. 视觉与交互（对照 docs/design/design-spec.md 的「视觉验收要点」）
- [ ] 明/暗主题两套完整实现，切换即时生效且持久化（localStorage "supermdp:theme"）
- [ ] 阅读区排版：行高/字号/标题层级/最大宽度符合规范；中英文混排正常
- [ ] 代码块头部（语言标签+复制）样式统一，hljs 配色与整体色板和谐
- [ ] 表格/引用/任务列表/图片样式符合规范
- [ ] TOC 目录栏：滚动跟随高亮（scrollspy）、可折叠、激活项样式正确
- [ ] 工具栏/状态栏/空状态/拖拽遮罩/设置弹层与 ui.css 一致
- [ ] 无花哨元素：无渐变滥用、无发光、无动画堆积；过渡克制（150-200ms）
- [ ] 窗口 900/1280/1600 宽度下均无布局破损

## J. 代码质量
- [ ] 前端 tsc 严格模式通过，无 any 滥用
- [ ] Go 代码 gofmt 干净、错误处理完整（读文件/对话框取消等路径）
- [ ] 依赖无冗余；不引入体积爆炸的库（mermaid 懒加载或按需）
- [ ] git 提交信息有意义、分步合理

## K. 严格只读
- [ ] 界面无任何编辑入口（无 contenteditable、无 textarea 编辑、无保存按钮）
- [ ] 无导出/打印/复制为 HTML 等导出功能入口

## 复验（T5 修复后）
- [ ] 上轮缺陷全部修复且无回归（重点回归 B/D/E/F/I 各抽 3 项）

---
*验收者：每项记录 PASS/FAIL + 证据（输出/命令/截图路径）。全部 PASS 或已列明可接受偏差才可标记 T4 完成。*
